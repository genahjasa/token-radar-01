Token Radar ranks every pre-token protocol in a sealed DefiLlama snapshot by implied launch value: the 40 watchlist protocols plus 186 early ones below the floor. It produces a static dashboard with the board, a detail view per protocol, and a farm plan for each. The model prices each protocol with the median market-cap to TVL of live-token protocols in its own category, adjusted for 7-day growth and how long it has gone without a token. The implied value is a model estimate, not a market price.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
